# לו"ז הפרויקט: קוד העמוד

עמוד גאנט אינטראקטיבי לפרויקט. **הריפו הזה פומבי ומכיל קוד בלבד.** נתוני הלו"ז נשמרים בריפו הפרטי של הפרויקט, בענף `schedule-data`, בקובץ `schedule.json`. בלי טוקן של GitHub עם גישה לריפו הפרטי, העמוד מציג רק מסך התחברות.

אין לשמור כאן שמות, תאריכים אמיתיים או כל נתון אחר מהלו"ז.

## איך זה עובד

- העמוד הוא קבצים סטטיים בלי שלב בנייה ובלי ספריות חיצוניות, ומתפרסם מ-`main` דרך GitHub Pages.
- כל משתמש מתחבר עם טוקן אישי, שנשמר רק בדפדפן שלו ונשלח רק אל `api.github.com`.
- שמירה היא commit לענף הנתונים, אוטומטית 15 שניות אחרי השינוי האחרון.
- אם שניכם ערכתם במקביל, השינויים ממוזגים לפי משימה. אם אותה משימה השתנתה משני הצדדים, נשמרת הגרסה של מי ששמר אחרון, העמוד מציג הודעה, והגרסה השנייה נשארת בהיסטוריה של הענף.

## פריסות התרשים

- **לפי כותרות:** המשימות של כל כותרת חולקות שורות, כשהשמות לא נוגעים זה בזה.
- **הכול יחד:** הכותרות בראש התרשים, וכל המשימות חולקות שורות בלי קשר לכותרת. זו הפריסה הכי צפופה.
- **שורה לכל משימה:** טבלה מלאה עם סטטוס, אחראי, תאריכים ומרווח.

הפריסה נשמרת בכל דפדפן בנפרד ולא משנה את הנתונים.

## עריכה מהירה

- **תלות:** גוררים את העיגול הקטן שבפינת הקצה של משימה אל משימה אחרת, והיא תתחיל אחריה. תלות מעגלית נחסמת.
- **סדר וכותרות:** בפריסה "שורה לכל משימה" גוררים שורה בטבלה. בפריסה "לפי כותרות" גוררים משימה בתרשים למעלה או למטה אל כותרת אחרת. בשתי הפריסות אפשר לגרור כותרת כדי לשנות את הסדר שלהן.
- **מקלדת:** Delete מוחק את המשימה הפתוחה, החצים מזיזים אותה ביום ועם Shift בשבוע, ו-? פותח את רשימת כל הקיצורים. Ctrl+Z מבטל עד 60 צעדים, ו-Ctrl+Y משחזר.
- **מי ומתי:** בכל משימה רשום מי יצר אותה ומי עדכן אותה לאחרונה, ומתי. השם נלקח מהחשבון ב-GitHub לפי השדה `github` ב-`people`. בראש העמוד רשום לפני כמה זמן נשמר ומי שמר, או שיש שינויים שעוד לא נשמרו.

## יומן עבודה

לשונית "יומן" וחלק בחלונית של כל משימה. כל רישום כולל תאריך, מי, שעות וטקסט, ואפשר לחבר אותו למשימה או להשאיר אותו כללי. בלשונית יש סינון, סיכום שעות, העתקה כטקסט לדו"ח וייצוא CSV.

ביומן אין תמונות, בכוונה: אין דרך לשמור אותן מהעמוד מחוץ ל-git, וב-git גם תמונה שנמחקה נשארת בהיסטוריה.

## בטלפון

הקישור לעמוד: https://interactive-driver-dashboard-ee.github.io/project-schedule/

- בפעם הראשונה בכל טלפון מדביקים את הטוקן, והוא נשמר בדפדפן של הטלפון.
- כל הכלים נמצאים גם בטלפון. מעבר ללשוניות ול"+ משימה", הם מתקפלים מאחורי הכפתור "עוד כלים", יחד עם המקרא.
- נגיעה במשימה פותחת את חלונית העריכה, ושם משנים תאריכים, תלויות וכל השאר. גרירה באצבע גוללת את התרשים ולא מזיזה משימות.
- אפשר להוסיף את העמוד למסך הבית ("הוספה למסך הבית" ב-Safari או ב-Chrome), והוא ייפתח כמו אפליקציה. באייפון זה נחשב דפדפן נפרד, אז מדביקים את הטוקן פעם אחת גם שם.

## מבנה הנתונים

`schedule.json` הוא מסמך עם השדות `title`, `projectStart`, `settings`, `people`, `phases`, `blackouts`, `baselines`, `tasks` ו-`log`. לכל משימה:

| שדה | משמעות |
| --- | --- |
| `id` | מזהה קבוע |
| `name`, `nameEn` | שם, ושם אופציונלי באנגלית לייצוא |
| `phase`, `track` | שלב, ומסלול: `hw`, `fw`, `veh` או `docs` |
| `type` | `task`, `milestone`, `gate` או `deadline` |
| `owner`, `backup` | מזהה אדם, או `both` |
| `status`, `progress` | `todo`, `doing`, `blocked` או `done`, ואחוז התקדמות |
| `duration` | ימי עבודה. ימים בתקופה חסומה לא נספרים |
| `start` | לא להתחיל לפני התאריך הזה |
| `fixed` | תאריך קבוע של מועד או שער |
| `deps` | `[{ "id": "...", "lag": 0 }]`: מתחילה אחרי שהמשימות האלה מסתיימות |
| `external`, `noPause` | ממשיכה גם בתקופות חסומות |
| `unverified`, `decision` | תאריך לא מאומת, החלטה פתוחה |
| `criteria`, `criteriaDone` | תנאי מעבר או סיום |
| `issue` | מספר Issue בריפו הפרטי |
| `shape`, `color`, `emphasis` | עיצוב אופציונלי. הערכים מוגדרים ב-`STYLE` בתוך `js/gantt.js` |
| `note` | הערות |
| `created`, `updated` | `{ "by": "...", "at": "..." }`: מי יצר ומי עדכן לאחרונה. נשמר רק העדכון האחרון |

כל רישום ב-`log` כולל `id`, `date`, `by`, `hours`, `text`, ואופציונלית `task`. אם המשימה נמחקה, שמה נשמר ב-`taskName`.
