# לו"ז הפרויקט: קוד העמוד

עמוד גאנט אינטראקטיבי לפרויקט. **הריפו הזה פומבי ומכיל קוד בלבד.** נתוני הלו"ז נשמרים בריפו הפרטי של הפרויקט, בענף `schedule-data`, בקובץ `schedule.json`. בלי טוקן של GitHub עם גישה לריפו הפרטי, העמוד מציג רק מסך התחברות.

אין לשמור כאן שמות, תאריכים אמיתיים או כל נתון אחר מהלו"ז.

## איך זה עובד

- העמוד הוא קבצים סטטיים בלי שלב בנייה ובלי ספריות חיצוניות, ומתפרסם מ-`main` דרך GitHub Pages.
- כל משתמש מתחבר עם טוקן אישי, שנשמר רק בדפדפן שלו ונשלח רק אל `api.github.com`.
- שמירה היא commit לענף הנתונים, אוטומטית 15 שניות אחרי השינוי האחרון.
- אם שניכם ערכתם במקביל, השינויים ממוזגים לפי משימה. אם אותה משימה השתנתה משני הצדדים, נשמרת הגרסה של מי ששמר אחרון, העמוד מציג הודעה, והגרסה השנייה נשארת בהיסטוריה של הענף.

## פריסות התרשים

- **לפי כותרות:** המשימות של כל כותרת חולקות שורות, כשהשמות לא נוגעים זה בזה.
- **הכול יחד:** הכותרות בראש התרשים, וכל המשימות חולקות שורות בלי קשר לכותרת. זו הפריסה הכי צפופה.
- **שורה לכל משימה:** טבלה מלאה עם סטטוס, אחראי, תאריכים ומרווח.

הפריסה נשמרת בכל דפדפן בנפרד ולא משנה את הנתונים.

## שינוי הקוד

| קובץ | תפקיד |
| --- | --- |
| `js/model.js` | תזמון, מרווחים, זיהוי בעיות ומיזוג. בלי תלות בדפדפן |
| `js/gantt.js` | ציור התרשים |
| `js/app.js` | מצב העמוד, טבלה, גרירה, שמירה |

להרצה מקומית עם נתוני דוגמה ובלי טוקן (צריך Node 22 ומעלה):

```bash
node dev/mock-server.mjs
```

ואז לפתוח את `http://localhost:8765/?mock`.

בדיקות:

```bash
npm test
```

```bash
node dev/e2e.mjs
```

הראשונה בודקת את הלוגיקה ורצה גם ב-GitHub Actions. השנייה מפעילה Edge או Chrome מקומי עם עכבר אמיתי, ובודקת גרירה, שמירה, מיזוג וייצוא.

## מבנה הנתונים

`schedule.json` הוא מסמך עם השדות `title`, `projectStart`, `settings`, `people`, `phases`, `blackouts`, `baselines` ו-`tasks`. לכל משימה:

| שדה | משמעות |
| --- | --- |
| `id` | מזהה קבוע |
| `name`, `nameEn` | שם, ושם אופציונלי באנגלית לייצוא |
| `phase`, `track` | שלב, ומסלול: `hw`, `fw`, `veh` או `docs` |
| `type` | `task`, `milestone`, `gate` או `deadline` |
| `owner`, `backup` | מזהה אדם, או `both` |
| `status`, `progress` | `todo`, `doing`, `blocked` או `done`, ואחוז התקדמות |
| `duration` | ימי עבודה. ימים בתקופה חסומה לא נספרים |
| `start` | לא להתחיל לפני התאריך הזה |
| `fixed` | תאריך קבוע של מועד או שער |
| `deps` | `[{ "id": "...", "lag": 0 }]`: מתחילה אחרי שהמשימות האלה מסתיימות |
| `external`, `noPause` | ממשיכה גם בתקופות חסומות |
| `unverified`, `decision` | תאריך לא מאומת, החלטה פתוחה |
| `criteria`, `criteriaDone` | תנאי מעבר או סיום |
| `issue` | מספר Issue בריפו הפרטי |
| `note` | הערות |
